# Inferential Statistics

Repositorio de la clase de Estadística Inferencial. Contiene la práctica de introducción a NumPy y la simulación de distribuciones muestrales (base del Teorema del Límite Central).

## Contenido

- `Inferential_Statistics.ipynb` — Notebook con dos partes:
  1. **Introducción a NumPy**: conversión de listas a arreglos, acceso a elementos, operaciones vectoriales y creación de matrices.
  2. **Distribución muestral**: simulación de una población y comparación de las medias muestrales con distintos tamaños de muestra (n = 5, 30, 100), para observar cómo la distribución de las medias se aproxima a una normal conforme crece n.

## Cómo correrlo

1. Abrir el notebook directo en [Google Colab](https://colab.research.google.com/) (Archivo → Abrir notebook → GitHub → pegar el link de este repo).
2. Ejecutar todas las celdas en orden (Entorno de ejecución → Ejecutar todo).
